## About

Kasign is a graphic design practice focused mostly on print and editorial design, often built with original photography.

## Services

- **Print**
- **Identity**
- **Typography**
- **Editorial**

## Work shown on the site

- **Calendars** for 2019 through 2026, combining photos, quotes, and U.S. federal or Nepali holiday dates. Today's calendars also live in the app [Kalendar by Kasign](https://kartproduction.github.io/kalendarbykasign/).
- **Wallpapers** made entirely from original photography
- **Identity and editorial pieces**, such as a visual identity, a magazine spread, and a package redesign
- **Posters and flyers**, including an awareness poster and a seasonal flyer
- **Design writing**, such as a short history of the Bauhaus movement

## What's on the site

A single page with these sections:

- **Home:** an introduction and the four services
- **Design blog:** dated project write-ups, each with its own page
- **About:** the design principles behind the work
- **Contact:** ways to get in touch

## How it was made

A static single-page website hosted on GitHub Pages. It uses hash-based navigation (for example `#blog` and `#about`), a theme toggle, and a responsive layout.
